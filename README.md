# REDHEAL COMPANY (레드힐컴퍼니)

2018년 설립 이래 주식·가상자산 알고리즘 트레이딩 솔루션을 제공해 온 대한민국 핀테크 기업입니다.
검증된 실전 투자 솔루션을 REDH 토큰 기반 Web3 멤버십 구조로 연결하는 실사용형 투자 생태계를 만들고 있습니다.

## 4대 서비스

| 서비스 | 내용 |
|---|---|
| AI 기반 급등주 탐지 (Smart Scanner) | 수급·패턴 기반 실시간 종목 필터링 |
| 주식 알고리즘 오토트레이딩 (Stock Auto-Trading) | 국내·해외 주식 자동매매 엔진 |
| 코인 퓨처스 퀀트 (Crypto Futures Quant) | 변동성 돌파·추세 추종 전략 봇 |
| 인사이트 & 리포트 (Expert Insight) | 시황 해설·데일리 리포트 |

## REDH 토큰

| 항목 | 값 |
|---|---|
| Name / Symbol | Redheal / **REDH** |
| Standard / Chain | ERC-20 (ERC20Burnable) / Polygon (PoS) |
| Contract | `0x226a6e9e1c5815b3037b461d7e53aa952c06f518` |
| Total Supply | 1,500,000,000 REDH (추가 발행 없음) |
| Security Audit | Verichains (2025-05-09) — [Redheal repo](https://github.com/redhealcompany/Redheal) |
| Legal Opinion | 법무법인 창천 (2025-05-12) — [Redheal repo](https://github.com/redhealcompany/Redheal) |

REDH는 서비스 이용을 위한 유틸리티 토큰이며 이익 공유·배당 구조가 없습니다. 투자의 최종 판단과 책임은 이용자 본인에게 있습니다.
